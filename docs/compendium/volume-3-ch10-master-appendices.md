# II. SESSION PREPARATION CHECKLIST

Before each session:

- [ ] Review previous session notes.
- [ ] Update faction actions.
- [ ] Update world-state.
- [ ] Review NPC motivations.
- [ ] Prepare important locations.
- [ ] Prepare likely encounters.
- [ ] Prepare names.
- [ ] Prepare rewards.
- [ ] Prepare consequences.
- [ ] Review player goals.

Avoid preparing player decisions.

---

# III. IMPROVISATION FRAMEWORK

Whenever surprised, answer these questions:

1. What would logically happen?
2. Who benefits?
3. Who suffers?
4. What changes immediately?
5. What changes later?
6. Which factions notice?
7. What new opportunity appears?

Improvisation should emerge from established world logic.

# XII. FLINT'S TWENTY PRINCIPLES

1. Prepare situations, not scripts.
2. Every important NPC wants something.
3. Every faction acts independently.
4. Every location has history.
5. The world changes without the heroes.
6. Player agency is sacred.
7. Failure creates new stories.
8. Consistency builds trust.
9. Mysteries require answers.
10. Foreshadow before revealing.
11. Villains act before heroes arrive.
12. Consequences outlive sessions.
13. Geography shapes history.
14. Economy shapes politics.
15. Politics shape conflict.
16. Magic changes civilization.
17. Every dungeon tells a story.
18. Every reward has meaning.
19. Campaigns evolve.
20. The best moments are the ones no one planned.

# THE FLINT MASTER DIRECTIVE

The Dungeon Master is not responsible for creating the perfect campaign.

The Dungeon Master is responsible for creating a world where:

• Choices matter.
• Consequences persist.
• Players are surprised.
• NPCs pursue their own lives.
• History accumulates.
• Wonder remains possible.

When those conditions exist, great campaigns emerge naturally.

Run the world honestly.

Let the players change it.
