# I. ENCOUNTER PHILOSOPHY

Every encounter should answer one question:

**"What changes after this?"**

An encounter exists to create change.

That change may involve:

• Resources
• Story
• Information
• Relationships
• Position
• Time
• Emotion

If nothing changes...

...the encounter probably shouldn't exist.

---

# II. THE ANATOMY OF AN ENCOUNTER

Every encounter contains five pieces.

## 1. Goal

Examples

• Kill the monster
• Escape
• Rescue
• Delay
• Steal
• Protect
• Investigate
• Negotiate

Never assume combat is the goal.

## 2. Opposition

Examples

• Monsters
• Guards
• Environment
• Time
• Politics
• Disease
• Puzzle
• Weather

## 3. Space

Examples

• Narrow bridge
• Tavern
• Cathedral
• Forest
• Canyon
• Airship
• Flooded chamber

Location changes gameplay.

## 4. Pressure

Pressure keeps players moving.

Examples

• Fire spreads
• Reinforcements
• Ritual countdown
• Rising water
• Collapsing cave
• Hostages

## 5. Consequences

Winning should matter.

Losing should matter.

Leaving should matter.

• De-escalate violence

**Exploration**

Purpose

• Discovery
• Navigation
• Mystery

Purpose

• Player reasoning

**Hazard**

Purpose

• Survival
• Adaptation

Purpose

# IV. COMBAT DESIGN

Good combat contains decisions.

Not repetition.

Ask:

Where should I move?

Who should I attack?

Should I conserve resources?

Should I retreat?

Can I exploit terrain?

Can I negotiate?

Can I complete another objective?

If players only repeat "I attack"...

...combat needs improvement.

---

# V. SOCIAL ENCOUNTERS

NPCs should want something.

Every important NPC has:

Goal

Fear

Need

Leverage

Weakness

Relationship

Players influence these variables.

Not a Persuasion check alone.

**Example**

King

Goal: Stop civil war

Fear: Assassination

Need: Proof

Weakness: Pride

Leverage: His daughter trusts the party

---

# VI. EXPLORATION ENCOUNTERS

Exploration isn't walking.

Exploration answers:

Where are we?

What's here?

Is it dangerous?

Should we continue?

Can we exploit this?

Examples

Hidden shrine

Collapsed bridge

Abandoned camp

Ancient battlefield

Magical storm

Unknown tunnel

Living forest

---

# VII. SKILL CHALLENGES

Use multiple skills.

One roll rarely tells an entire story.

**Example**

Escape burning city.

Athletics — Move debris.

Survival — Navigate smoke.

Medicine — Treat victims.

Persuasion — Calm civilians.

Arcana — Stabilize magical fire.

Each success changes the situation.

Failures also change it.

Never stall progress completely.

# VIII. BOSS BATTLES

Bosses need more than HP.

Use:

Phases

Environmental changes

Reinforcements

Objectives

Dialogue

Transformation

**Examples**

```
Phase One
Necromancer
    ↓
Phase Two
Summons undead
    ↓
Phase Three
Consumes souls
    ↓
Phase Four
Entire room collapses
```

Boss fights should evolve.

# IX. MINIONS, ELITES & LEGENDARY CREATURES

**Minions**

Purpose

Create battlefield movement.

Threat through numbers.

**Elite**

Purpose

Occupies multiple players.

Usually worth two creatures.

**Legendary**

Purpose

Fight entire party.

Needs:

Legendary Actions

Legendary Resistance

Interesting movement

Unique mechanics

Environmental interaction

# X. TERRAIN AS GAMEPLAY

Terrain should matter.

Examples

Lava

Ice

Water

Verticality

Darkness

Fog

Wind

Moving platforms

Rotating rooms

Bridges

Cover

Terrain creates choices.

Flat rooms create repetitive combat.

---

# XI. ENCOUNTER DIFFICULTY

Instead of asking

"Can they win?"

Ask

**"What resources will victory cost?"**

**Easy** — Little cost.

**Medium** — Meaningful decisions.

**Hard** — Significant resources.

**Deadly** — Failure possible without good play.

Never confuse Deadly with unfair.

---

# XII. ENCOUNTER PACING

Alternate intensity.

**Example**

```
Combat
    ↓
Roleplay
    ↓
Puzzle
    ↓
Combat
    ↓
Discovery
    ↓
Boss
```

Variation creates memorable sessions.

Continuous combat becomes exhausting.

---

# XIII. MULTI-STAGE ENCOUNTERS

The battlefield changes.

Examples

Bridge collapses.

Flood begins.

Walls rotate.

Magic fails.

Portal opens.

Dragon lands.

Cultists arrive.

Players adapt.

That's memorable.

---

# XIV. DYNAMIC OBJECTIVES

Objectives beyond killing.

Examples

Stop ritual.

Protect NPC.

Escape alive.

Destroy crystal.

Hold bridge.

Survive ten rounds.

Recover artifact.

Close portal.

Delay enemy.

This creates tactical diversity.

Random ≠ meaningless.

Random encounters reveal:

Ecology

Faction movement

Time pressure

Atmosphere

Rumors

Changing world

Examples

Merchant

Refugees

Patrol

Lost child

Monster migration

Collapsed road

Traveling priest

Every encounter should teach something.

---

# XVI. ENCOUNTER AUDIT

- [ ] Does the encounter change something?
- [ ] Does terrain matter?
- [ ] Are multiple solutions possible?
- [ ] Is failure interesting?
- [ ] Does it reinforce theme?
- [ ] Are consequences clear?
- [ ] Does it reveal information?
- [ ] Is pacing appropriate?
- [ ] Does it avoid repetition?
- [ ] Will players remember it?

---

# DAVIS' ENCOUNTER GOLDEN RULE

The players should remember

**WHY**

they fought—

not simply

**WHAT**

they fought.

Every memorable encounter changes the world,
the characters,
or the story.

Preferably all three.
